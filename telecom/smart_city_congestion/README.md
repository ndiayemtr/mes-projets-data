🚦 Smart City Traffic Congestion Prediction

Développement d’un système de prédiction de congestion urbaine basé sur des données de trafic, météo et événements.

🎯 Objectif
Anticiper les situations de congestion critique pour améliorer la gestion du trafic urbain.

⚙️ Méthodologie
- Feature engineering avancé (traffic_intensity, speed_efficiency, etc.)
- Gestion du déséquilibre de classes
- Optimisation du modèle (Random Forest)
- Ajustement du seuil métier pour maximiser la détection des congestions

📊 Dashboard
- KPI en temps réel
- Filtres dynamiques (zone, météo)
- Simulation utilisateur
- Recommandations opérationnelles

🚀 Résultat
Modèle capable de détecter efficacement les situations critiques avec un bon compromis précision / recall.
